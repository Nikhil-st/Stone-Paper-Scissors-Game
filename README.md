🪨 Stone Paper Scissors Game



A fun and interactive Stone Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer, make your move, and see who wins!



🌐 Live Demo



\[Play the Game](https://nikhil-st.github.io/Stone-Paper-Scissors-Game/)



✨ Features



\- Interactive gameplay

\- Player vs. computer

\- Random computer choices

\- Winner and draw detection

\- Simple and user-friendly interface



🛠️ Technologies Used



\- HTML5

\- CSS3

\- JavaScript



🚀 Run Locally



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/Nikhil-st/Stone-Paper-Scissors-Game.git

&#x20;  ```



2\. Open the project folder in VS Code.

3\. Open `index.html` in your browser or use the Live Server extension.
